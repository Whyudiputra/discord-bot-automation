# 🤖 Discord Automation Bot

Repositori ini berisi kode sumber untuk bot Discord kustom yang saya bangun untuk menangani automasi dan manajemen server secara mandiri. Proyek ini membuktikan pemahaman saya dalam pengembangan logika backend dan infrastruktur server.

### 🚀 Fitur Utama
*   **24/7 Connectivity**: Dijalankan menggunakan Virtual Private Server (VPS) untuk memastikan bot selalu aktif tanpa henti.
*   **Server Management**: Automasi tugas moderasi dan manajemen interaksi user di dalam server.
*   **Performance Optimized**: Dibangun dengan Node.js untuk memastikan penggunaan resource (RAM/CPU) tetap efisien di lingkungan VPS.

### 💻 Stack Teknologi
*   **Runtime**: Node.js[cite: 1].
*   **Language**: JavaScript[cite: 1].
*   **Library**: Discord.js.
*   **Environment**: Linux / VPS Terminal[cite: 1].

### 🛠️ Pengaturan & Deployment
1. **Local Setup**: Clone repo dan jalankan `npm install` untuk menginstal dependensi.
2. **Configuration**: Atur token bot dan prefix perintah di file config.
3. **VPS Hosting**: Di-deploy menggunakan PM2 atau sistem manajemen proses lainnya agar bot tetap jalan setelah terminal ditutup[cite: 1].
